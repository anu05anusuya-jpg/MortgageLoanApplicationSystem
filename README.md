
# 🏠 Mortgage Loan Application Management System

## 📌 Project Overview

The Mortgage Loan Application Management System is a Java-based project designed to organize and manage mortgage loan application information. This project demonstrates the practical application of Java programming and Object-Oriented Programming (OOP) concepts.

## 🎯 Objectives

- Manage mortgage loan applicant information.
- Organize loan application details.
- Apply object-oriented design principles.
- Improve understanding of Java application development.

## ✨ Features

- Store and display applicant details.
- Manage mortgage loan application information.
- Organize application data using Java classes and objects.
- Implement loan-related business logic.

## 🛠️ Technologies Used

- Java
- Core Java
- Object-Oriented Programming (OOP)
- IntelliJ IDEA

## 🧠 OOP Concepts

- **Encapsulation:** Organize and protect application data.
- **Inheritance:** Reuse common properties and behaviours.
- **Abstraction:** Represent essential loan application operations.
- **Polymorphism:** Support different implementations of common behaviours.

*Keep only the concepts implemented in your actual project.*

## ⚙️ Prerequisites

- Java Development Kit (JDK)
- IntelliJ IDEA or another Java IDE

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Configure the required JDK.
4. Open the main Java class.
5. Run the `main()` method.
6. View the application output.
